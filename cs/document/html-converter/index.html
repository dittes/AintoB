Co je HTML?

HTML je standardní značkovací jazyk pro webový obsah. Soubory HTML popisují strukturu webové stránky – nadpisy, odstavce, odkazy, obrázky, tabulky – pomocí hierarchie prvků a značek. Je to univerzální výstupní formát webového obsahu, který lze převádět do formátů dokumentů a prostého textu i zpět.

Běžné využití formátu HTML

  • Export webového obsahu pro čtení offline
  • Převod webových stránek na upravitelné dokumenty
  • Archivace HTML zpráv jako PDF nebo prostého textu
Poznámka: Složité rozvržení, interakce v JavaScriptu a externí zdroje (CSS, obrázky) se při převodu HTML do jiných formátů nemusí přenést přesně.

Kompatibilita: Univerzální – každý prohlížeč HTML nativně zobrazí.
