What is WMV?

WMV is the Windows Media Video format that Microsoft introduced in 1999 for streaming and playback on Windows. It stores video in an ASF container and still turns up in old camera footage, screen recordings and corporate archives.

Common uses for WMV

  • Opening old Windows recordings on a phone, tablet or Mac
  • Converting legacy company videos to MP4 for sharing
  • Creating WMV for older Windows software that requires it
Note: Browsers and phones cannot play WMV natively and the format is considered obsolete. Files created here use the classic WMV2 codec for maximum Windows compatibility.

Compatibility: Windows Media Player, VLC and most desktop players. Not playable in browsers, on iPhone or in most Android galleries.
