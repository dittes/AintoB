What is ODT?

ODT is the word-processing format of the OpenDocument standard, used by LibreOffice, OpenOffice and many public authorities. It keeps text, styles and images in a ZIP package of XML files and is an open ISO standard.

Common uses for ODT

  • Opening LibreOffice documents without LibreOffice
  • Public-sector and long-term archives that require open standards
  • Sharing editable text with people who do not use Microsoft Word
Note: Complex layouts, tracked changes and macros can look different when an ODT file is opened in another program. Conversions here keep text, headings, lists, tables and basic formatting.

Compatibility: Native in LibreOffice and Apache OpenOffice; opens in Microsoft Word 2010+, Google Docs and Apple Pages.
