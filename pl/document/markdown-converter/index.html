Czym jest Markdown?

Markdown to lekka, czytelna składnia formatowania zwykłego tekstu, stworzona przez Johna Grubera i Aarona Swartza. Prostymi znakami oznacza się nagłówki, pogrubienia, kursywę, odnośniki, kod i listy – a tekst czysto przekształca się do HTML. Markdown to de facto standard dla plików README, dokumentacji i pisania technicznego.

Typowe zastosowania formatu Markdown

  • Pisanie dokumentacji i plików README dla repozytoriów kodu
  • Wpisy blogowe i artykuły techniczne w generatorach stron statycznych
  • Konwersja do HTML lub PDF w celu publikacji i udostępniania
Uwaga: Różne odmiany Markdown (CommonMark, GFM, kramdown) mają nieco inną składnię – złożone tabele lub własne rozszerzenia mogą nie przenieść się idealnie między narzędziami.

Zgodność: Obsługują go GitHub, VS Code, Notion, Obsidian, Hugo, Jekyll i praktycznie wszystkie narzędzia programistyczne.
