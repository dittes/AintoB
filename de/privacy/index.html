Datenschutzerklärung

Stand: 17. Oktober 2026

1. Welche Daten erheben wir?

AintoB.com ist ein browserbasiertes Werkzeug zur Dateiumwandlung. Dateien, die Sie umwandeln, werden nie auf unsere Server hochgeladen. Die gesamte Verarbeitung findet lokal in Ihrem Browser mit JavaScript statt.

Wenn Sie Analyse-Cookies zustimmen, erheben wir möglicherweise grundlegende anonymisierte Analysedaten (aufgerufene Seiten, ungefährer Standort auf Länderebene, Browsertyp). Diese Daten werden nie mit persönlichen Kennungen verknüpft.

2. Cookies

Standardmäßig verwenden wir nur notwendige Cookies. Sie ermöglichen grundlegende Funktionen der Website (zum Beispiel das Speichern Ihrer Cookie-Auswahl). Ohne Ihre ausdrückliche Einwilligung verwenden wir keine Tracking-Cookies.

Ihre Cookie-Einstellungen können Sie jederzeit über das Cookie-Banner ändern.

3. Umgang mit Dateien

Dateien, die Sie zur Umwandlung auswählen, werden vollständig in Ihrem Browser verarbeitet. Sie werden nie an unsere Server übertragen. Wir haben technisch keine Möglichkeit, auf den Inhalt Ihrer Dateien zuzugreifen.

4. Dienste Dritter

Wir laden Bootstrap-CSS und -JavaScript sowie einige Umwandlungsbibliotheken von einem CDN (cdn.jsdelivr.net). Das CDN kann nach seiner eigenen Datenschutzerklärung Anfragedaten (IP-Adresse, Zeitstempel) protokollieren. Wir geben keine personenbezogenen Daten an CDN-Anbieter weiter.

Unsere Seiten verlinken auf die eigenständige Website open-online.com. Wenn Sie einem solchen Link folgen, gilt die Datenschutzerklärung dieser Website.

5. Ihre Rechte (DSGVO)

Wenn Sie sich in der EU oder im EWR befinden, haben Sie das Recht auf Auskunft, Berichtigung oder Löschung der über Sie gespeicherten personenbezogenen Daten. Da wir nur minimal personenbezogene Daten erheben, sind die meisten Anfragen unkompliziert. Wenden Sie sich für Datenanfragen über die Seite Impressum an uns.

6. Kontakt

Bei Fragen zum Datenschutz finden Sie die Kontaktdaten auf unserer Seite Impressum.
