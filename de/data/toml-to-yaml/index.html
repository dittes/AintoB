Warum TOML in YAML umwandeln?

Konfiguration zwischen Ökosystemen übertragen: Dieser Konverter liest TOML und schreibt gut lesbares YAML mit derselben Struktur.

Typische Anwendungsfälle

  • Sie haben eine TOML-Datei und brauchen sie im Format YAML.
  • Die Zielsoftware oder -plattform verlangt YAML, Ihre Datei liegt aber als TOML vor.
  • Typischer Einsatz von YAML: Kubernetes-Manifeste und Docker-Compose-Dateien.
  • Sie möchten die Dateigröße verringern oder die Kompatibilität verbessern, ohne Desktop-Software zu verwenden.
Gut zu wissen: Wegen der Einrückungsempfindlichkeit lässt sich YAML durch ein falsches Leerzeichen leicht beschädigen, und die implizite Typisierung (das „Norwegen-Problem“) kann überraschen.

  2. Passen Sie bei Bedarf die Ausgabeeinstellungen für YAML an.
  3. Klicken Sie auf Umwandeln und laden Sie die fertige Datei sofort herunter.

Über die Formate

⚙️

TOML (Tom's Obvious Minimal Language)

TOML ist ein Konfigurationsformat, das für Menschen leicht les- und schreibbar sein soll. Es wird von Rust (Cargo), Python (pyproject.toml), Hugo und vielen weiteren Werkzeugen genutzt und bildet ein Verzeichnis von Werten klar ab.

Kompatibilität: Von Bibliotheken für alle gängigen Programmiersprachen unterstützt.

📋

YAML (YAML Ain't Markup Language)

YAML ist ein menschenfreundliches Datenformat, das statt Klammern und Anführungszeichen Einrückungen verwendet. Es ist der De-facto-Standard für Konfigurationsdateien – Kubernetes, Docker Compose, GitHub Actions und CI-Pipelines sprechen alle YAML – und bildet dasselbe Datenmodell ab wie JSON.

Kompatibilität: Von allen großen Sprachen über Bibliotheken unterstützt. Browser lesen YAML nicht von sich aus – deshalb gibt es Konverter.
