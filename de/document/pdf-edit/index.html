Was der PDF-Editor kann

📂

Zusammenfügen

Fügen Sie beliebig viele PDFs in der gewählten Reihenfolge zu einer Datei zusammen. Nützlich für Berichte, Verträge oder mehrteilige Dokumente.

✂️

Teilen

Extrahieren Sie einen bestimmten Seitenbereich in ein eigenes PDF. Geben Sie einen beliebigen Bereich wie 1-5 oder 2,4,7-10 ein, um genau die Seiten zu erhalten, die Sie brauchen.

🔄

Drehen & Löschen

Korrigieren Sie quer oder kopfüber stehende Seiten, indem Sie sie jeweils um 90° drehen. Entfernen Sie unerwünschte Seiten vor dem Teilen. Alle Änderungen werden in einem Durchgang angewendet.

💧

Wasserzeichen

Setzen Sie einen diagonalen Textstempel – etwa VERTRAULICH, ENTWURF oder Ihren Firmennamen – auf jede Seite. Mit Farbe und Deckkraft steuern Sie die Sichtbarkeit.

So bearbeiten Sie ein PDF

  1. Wählen Sie das passende Werkzeug: Zusammenfügen, Teilen, Drehen & Löschen oder Wasserzeichen.
  2. Wählen Sie Ihre PDF-Datei aus (oder mehrere Dateien zum Zusammenfügen).
  3. Stellen Sie die Optionen ein – Seitenbereiche, Drehung, Wasserzeichen-Text und so weiter.
  4. Klicken Sie auf die Schaltfläche und laden Sie das fertige PDF sofort herunter.
